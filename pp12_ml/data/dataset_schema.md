# Dataset schema

Файл: `construction_tasks_dataset.csv`

## Столбцы

- `id` - целочисленный идентификатор строки датасета.
- `title` - короткое название строительной задачи в стиле карточки WPF-приложения.
- `category` - целевая категория для классификатора.
- `reference_description` - эталонное деловое описание задачи для prompt-примеров и проверки стиля.
- `source_type` - происхождение записи.

## Значения `source_type`

- `project` - запись взята из текущего проекта или локальных проектных примеров.
- `simulated` - правдоподобная синтетическая запись для учебного датасета.
- `open_source` - запись подготовлена по открытым типовым формулировкам.

На Phase 1 датасет заполнен `simulated`-примерами, чтобы не зависеть от локальной БД приложения и не менять WPF-код.

## Категории

- `бетонные` - работы с бетоном, армированием, опалубкой, стяжками и монолитными конструкциями.
- `монтажные` - установка и сборка строительных конструкций, проемов, кровли, лестниц, лесов и навесных элементов.
- `отделочные` - штукатурка, шпаклевка, окраска, плитка, напольные покрытия и подготовка поверхностей.
- `инженерные` - электрика, водоснабжение, канализация, отопление, вентиляция, слаботочные и инженерные сети.
- `снабженческие` - заявки, поставки, приемка, учет и перемещение материалов.
- `организационные` - планирование, координация, контроль, согласования, инструктажи и приемка этапов.

## Использование

`title` используется как вход для TF-IDF и классификации. `reference_description` используется для подбора похожих примеров при генерации prompt к LM Studio.
